# 2.4.0

Requests certified builds for every repository in the release candidate, recovers pending build identities and validates source, configuration, output and provenance evidence. Build readiness grants no deployment authority.

Supports `work.execution.run.v2` with explicit Task, Story, Epic or Release scope, assigned principal, planning/scope revisions and exact evidence. Preserves published V1 execution. Uses Agent.SDK 3.59.0 and WorkManagement.Contracts 3.25.0.

Task completion follows independent QA; task/story completion does not promote directly to the default branch. Manager acceptance and trusted release promotion remain separate from deployment or public release.
